A program that draws one newspaper front page summing up the world's news of Monday 23 November 2026 — 38 dated stories across 9 regions, led by the COP31 collapse, plus a 9-item "Also today" strip. Every story was verified against two or more outlets; tolls and market closes are the agreed figures, and disputed figures (Brent crude levels, the DRC Ebola case count, the Tonj East 87 claim) are left out.

## Run it

```sh
python3 draw.py && mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
